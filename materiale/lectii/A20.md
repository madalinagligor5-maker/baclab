## Tipuri de reproducere

Reproducerea asigură perpetuarea speciei. La plante, ea poate fi:

- **asexuată**: dintr-un singur părinte, fără gameți; urmașii sunt identici genetic cu părintele;
- **sexuată**: prin unirea a doi gameți (fecundație); urmașii sunt diferiți genetic între ei.

## Reproducerea asexuată

### Prin spori

Sporii sunt celule specializate care, în condiții favorabile, dau naștere unui nou organism. Se înmulțesc prin spori ciupercile, mușchii și ferigile.

### Reproducerea vegetativă

Un organ vegetativ (rădăcină, tulpină, frunză) sau o parte din el formează o plantă nouă.

**Natural**, prin:

- **stoloni**: tulpini târâtoare care se înrădăcinează la noduri (căpșunul);
- **rizomi**: tulpini subterane (irisul, pirul);
- **bulbi**: tulpini scurte cu frunze cărnoase (ceapa, laleaua);
- **tuberculi**: tulpini subterane îngroșate (cartoful).

**Artificial** (practicată de om), prin:

- **butași**: fragmente de ramuri puse la înrădăcinat (vița de vie, mușcata, salcia);
- **marcote**: ramuri îngropate în pământ fără să fie tăiate de la planta-mamă, până se înrădăcinează (vița de vie);
- **altoire**: un fragment de ramură (**altoiul**) se atașează pe o plantă înrădăcinată (**portaltoiul**); folosită la pomii fructiferi.

## Floarea

La angiosperme, **floarea** este organul reproducerii sexuate.

![[floare]]

Părțile florii, de la exterior spre interior:

- **pedunculul** (codița) și **receptaculul** (partea lățită pe care stau celelalte componente);
- **caliciul**, format din **sepale**, de obicei verzi, care protejează floarea în boboc;
- **corola**, formată din **petale**, adesea colorate, care atrag insectele;
- **androceul**: totalitatea **staminelor**, partea bărbătească. O stamină are un **filament** și o **anteră**, în care se formează **grăuncioarele de polen**;
- **gineceul**: totalitatea **carpelelor**, partea femeiască. Carpelele formează **pistilul**, cu trei părți: **stigmatul** (care primește polenul), **stilul** și **ovarul** (în care se află **ovulele**).

## Polenizarea

**Polenizarea** este transportul polenului de pe anteră pe stigmat. Poate fi:

- **autopolenizare**: polenul ajunge pe stigmatul aceleiași flori (mazărea, grâul);
- **polenizare încrucișată**: polenul ajunge pe stigmatul altei flori, cu ajutorul **vântului** (porumbul, nucul), al **insectelor** (mărul, floarea-soarelui) sau al apei.

## Dubla fecundație

După polenizare, grăunciorul de polen germinează pe stigmat și formează **tubul polenic**, care crește prin stil până la ovul. Prin el coboară **două spermatii** (gameți bărbătești).

În ovul se află **sacul embrionar**, cu **7 celule (8 nuclei)**, printre care **oosfera** (gametul femeiesc) și **nucleul secundar** (diploid).

Au loc **două fecundații**, de aceea se numește **dublă fecundație** (caracteristică angiospermelor):

- prima spermatie + **oosfera** → **zigotul principal (2n)**, din care se dezvoltă **embrionul**;
- a doua spermatie + **nucleul secundar** → **zigotul accesoriu (3n)**, din care se dezvoltă **endospermul** (țesutul nutritiv al seminței).

> [!retine]
> Zigotul principal este **diploid (2n)** și formează embrionul. Zigotul accesoriu este **triploid (3n)** și formează endospermul.

## Sămânța și fructul

După fecundație:

- **ovulul** se transformă în **sămânță**;
- **ovarul** se transformă în **fruct**.

**Sămânța** are un **tegument** (înveliș), un **embrion** (cu rădăcinuță, tulpiniță, mugur și unul sau două **cotiledoane**) și uneori **endosperm**.

**Fructele** se clasifică astfel:

| Tip | Subtip | Exemple |
| --- | --- | --- |
| **Cărnoase** | drupă (cu sâmbure) | prună, cireașă, piersică |
| | bacă (cu multe semințe în pulpă) | tomată, strugure, coacăză |
| | poamă (miez cu semințe în „casă”) | măr, pară, gutuie |
| **Uscate indehiscente** (nu se deschid) | nucă | alună |
| | achenă | floarea-soarelui |
| | cariopsă | grâu, porumb |
| **Uscate dehiscente** (se deschid) | păstaie | fasole, mazăre |
| | capsulă | mac, castan sălbatic |

> [!bac]
> „Din ce se formează sămânța și din ce se formează fructul?” Sămânța din **ovul**, fructul din **ovar**. Apare des la Subiectul I.A.
